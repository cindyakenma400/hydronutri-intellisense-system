# HydroNutri Intellisense System

A full-stack smart agriculture system using AI/ML.

## Features
- Soil assessment
- Crop recommendation
- Disease detection
- Irrigation planning
- Fertilization planning
- Sensor monitoring dashboard
- Pump and valve control from any device (computer, phone or tablet)
- Auto mode: the pump runs from soil moisture, with a maximum runtime safety cutoff
- ESP32 field controller firmware (soil sensor readings and relay control)
- Alerts and notifications
- Analytics and sensor history
- Mobile-friendly interface

## Tech Stack
- Frontend: Next.js + TypeScript
- Backend: FastAPI (Python)
- ML: Random Forest + CNN models
- Hardware: ESP32
